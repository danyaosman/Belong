# Development Roadmap

## Phase 1 – Project Setup

Goal

Set up the development environment and project structure.

Tasks

- Create GitHub repository
- Configure project structure
- Configure FastAPI
- Configure Next.js
- Configure React Native (Expo)
- Configure PostgreSQL
- Configure Docker
- Set up GitHub Project Board

Deliverable

Project structure with frontend and backend running.

Goal

Build the core backend infrastructure.

Tasks

- SQLAlchemy models
- Alembic migrations
- JWT authentication
- User management
- API structure

Deliverable

Working backend with authentication and database.
